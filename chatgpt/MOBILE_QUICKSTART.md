# ChatGPT Android Quickstart

## One-time project setup

1. Create a ChatGPT Project named **Furry Image Studio**.
2. Upload `PROJECT_LIBRARY.md` as a project file.
3. In Project settings, paste the text from `PROJECT_INSTRUCTIONS.md`.
4. Keep new transformation chats inside this Project. Its files, instructions,
   and project memory persist when you move between web and Android.

## On Android

1. Open the **Furry Image Studio** Project, then start a chat in it.
2. Attach the real photo. Attach character-reference images too when you have
   them.
3. Name the person and character naturally: for example, “Turn me into Moxie
   in Toon in Real World style.”
4. If the result has one defect, ask for one repair rather than restarting the
   entire request.

## Add a character by name

```text
Add a character named Juniper to this Project. She is a silver-gray wolf with a
white muzzle and chest, one teal forelock, round gold glasses, and a gentle
smile. Use expressive five-finger hands. Avoid extra ears, tails, or fingers.
Her default style is Toon in Real World. Remember this profile, and give me the
complete library entry to paste into PROJECT_LIBRARY.md.
```

## Starters

### Transform one person into Moxie

```text
Transform only me, the person holding the phone, into Moxie in Toon in Real
World style. Keep the photo's crop, pose, hands on the phone, room, lighting,
other people, objects, reflections, and visible text exactly as they are.
Moxie needs her orange-red fur, cream markings, purple cat-eye glasses,
side-swept auburn hair, and expressive five-finger hands. Do not redraw the
scene or add a tail unless it can attach visibly and naturally.
```

### Transform a chosen person into a supplied character

```text
Use the attached character reference as the character lock. Transform only the
person in the green jacket into that character in Toon in Real World style.
Preserve every other person, the background, crop, pose, clothing silhouette,
props, signs, shadows, and text. Do not restyle the whole photograph.
```

### Repair one defect

```text
Keep this generated image unchanged except for the selected subject's glasses:
repair them to symmetrical purple cat-eye glasses. Preserve the background,
crop, character markings, hands, clothing, props, text, and every other person.
```

### Make a full-scene illustration

```text
Create a new full-scene Storybook illustration of Moxie reading in a sunlit
window seat. Preserve Moxie's orange-red fur, cream markings, purple cat-eye
glasses, auburn side-swept hair, and soft confident expression. Keep the scene
simple, warm, and readable at phone size.
```
